# Clarion research workspace

This is the navigational root for the research program. The prior corpus run is retained under `research_artifacts/` as an immutable evidence set; this workspace links to it rather than moving or rewriting it. Reports label evidence VERIFIED, PARTIALLY VERIFIED, NOT EVALUATED, BLOCKED, or REFUTED. No metric without raw observations is reported as a result.

## Layout

- `protocols/`: frozen research questions and evaluation protocols.
- `reports/`: audit reports and publication-readiness assessment.
- `data/`: research tables, annotation data, and machine-readable source/literature indexes.
- `scripts/`: reproducible report and data preparation scripts.
- `results/`, `experiments/`, `figures/`, `tables/`, `annotation/`: reserved for executed study artifacts; see each README for current state.
- `manuscript/`: evidence-limited editable research draft.

## Existing evidence

Corpus extraction/indexing data, generated figures and scripts are in [`../research_artifacts/README.md`](../research_artifacts/README.md). Prior audit reports at repository root are historical evidence, not authority where they conflict with the conservative status in `reports/RESEARCH_VALIDATION_REPORT.md` or `reports/PUBLICATION_READINESS_REVIEW.md`.
